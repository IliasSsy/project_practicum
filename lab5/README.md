# SFML Platformer

Simple and fast C++ platformer with custom physic, hitboxes.

[Screenshot with gameplay is coming soon]

# Technologies

Programming Language: C++ (standard C++17)
Graphics biblio: SFML 2.6+
Build system: CMake

# Features

Custom Physics: Smooth movement, gravity and maximum speed checking by clamp
Smart Collision: Using "playerBounds" and "playerHitbox" for nice collision handling
Parkour Mechanics: 
* Wall sliding with gravity
* Wall jumping in opposite direction
FPS Indepence: Physical created by Delta Time.
